# 复杂接口运行流程

## 说明

以下流程沿真实的 `Controller → Service/ServiceImpl → Mapper/第三方组件/Redis → 数据库` 调用链整理。图中的异常分支、事务、状态字段与方法名均来自源码；注释中标为 TODO 或被注释掉的商业版能力，没有写成已执行步骤。

## 1. 创建订单

- 请求：`POST /app-api/order/create`
- Controller：`AppOrderController#create`
- 核心 Service：`AppStoreOrderServiceImpl#createOrder`（`@Transactional`）
- 目的：校验商品与库存，计算价格/优惠，落订单及明细并安排超时取消。

```plantuml
@startuml
start
:AppOrderController.create 取得登录 uid;
:AppStoreOrderServiceImpl.createOrder;
if (堂食且桌号为空?) then (是)
  :抛出 STORE_ORDER_DESK_NOT;
  stop
endif
:读取 yshop_store_shop;
:尝试获取 Redisson 库存锁;
if (获得锁?) then (是)
  repeat
    :checkProductStock;
    :读取商品 SKU 价格并累计数量/金额;
  repeat while (仍有商品?) is (是)
  :释放锁;
else (否)
  :源码继续后续流程（未显式失败）;
endif
if (传入 couponId?) then (是)
  :读取 yshop_coupon_user;
  if (最低消费不满足?) then (是)
    :抛出 COUPON_NOT_CONDITION;
    stop
  endif
  :优惠券 status=已使用;
endif
:按外卖/自取计算 payPrice;
:生成 Snowflake orderId;
:插入 yshop_order_number;
if (外卖?) then (是)
  :校验并读取 yshop_user_address;
endif
:插入 yshop_store_order (paid=0);
if (保存失败?) then (是)
  :抛异常并回滚事务;
  stop
endif
:deStockIncSale 扣 SKU/商品库存并增销量;
:写 yshop_store_order_cart_info;
:写 yshop_store_order_status(create_order);
if (非堂食?) then (是)
  :加入 Redisson 延迟队列，超时自动取消;
endif
:返回 orderId;
stop
@enduml
```

## 2. 发起订单支付

- 请求：`POST /app-api/order/pay`
- Controller：`AppOrderController#pay`
- 核心 Service：`AppStoreOrderServiceImpl#pay`；余额分支进入 `yuePay`、`paySuccess`
- 第三方：`PayServiceManager`

```plantuml
@startuml
start
:根据 uni + uid 查询订单/用户流水;
if (两者都不存在?) then (是)
  :抛出 STORE_ORDER_NOT_EXISTS;
  stop
endif
if (已经支付?) then (是)
  :抛出 ORDER_PAY_FINISH;
  stop
endif
:读取会员与支付金额;
if (支付类型=微信?) then (是)
  if (来源=H5?) then (是)
    :创建 MWEB MerchantPayOrder;
    :manager.getOrderInfo;
    :读取 merchant_details.return_url;
    :返回带 redirect_url 的 mweb_url;
  elseif (来源=公众号?) then (是)
    :以 openid 创建 JSAPI 支付单;
    :manager.getOrderInfo;
  else (小程序)
    :以 routineOpenid 创建 JSAPI 支付单;
    :manager.getOrderInfo;
  endif
elseif (支付类型=余额?) then (是)
  :yuePay 校验余额;
  :扣减 yshop_user.now_money;
  :paySuccess 更新订单 paid/payType/payTime;
elseif (支付类型=支付宝?) then (是)
  :创建 WAP MerchantPayOrder;
  :manager.toPay;
endif
:返回支付参数或成功状态;
stop
@enduml
```

## 3. 支付回调与异步落账

- 请求：`ANY /app-api/order/notify/payBack{detailsId}.json`（源码使用未限定 method 的 `@RequestMapping`）
- Controller：`AppOrderController#payBack`
- 核心链路：`PayServiceManager#payBack` → `WxPayMessageHandler`/`AliPayMessageHandler` → `PayNoticeProducer` → `PayNoticeConsumer` → `AppStoreOrderServiceImpl#paySuccess`

```plantuml
@startuml
start
:接收支付平台回调 HttpServletRequest;
:manager.payBack(detailsId, NoticeRequest);
:支付组件验签并路由消息处理器;
if (平台交易成功?) then (否)
  :返回 FAIL;
  stop
endif
:提取 out_trade_no;
:PayNoticeProducer 写 Redis Stream 消息;
:立即向支付平台返回 SUCCESS/OK;
:PayNoticeConsumer.onMessage;
:paySuccess(orderId, payType);
if (匹配充值流水?) then (是)
  :流水 status=已支付;
  :充值类型则增加用户余额;
  stop
endif
if (订单不存在?) then (是)
  :记录日志后返回;
  stop
endif
:更新 yshop_store_order paid=1/payType/payTime;
:增加会员购买次数;
:写订单支付成功状态记录;
:写 yshop_user_bill 支出流水;
:符合条件时发送微信通知消息;
stop
@enduml
```

## 4. 取消未支付订单

- 请求：`POST /app-api/order/cancel`
- Controller：`AppOrderController#cancelOrder`
- 核心 Service：`AppStoreOrderServiceImpl#cancelOrder`（`@Transactional`）

```plantuml
@startuml
start
:按 orderId/uid 查询订单;
if (订单不存在?) then (是)
  :抛出 STORE_ORDER_NOT_EXISTS;
  stop
endif
if (paid != 0?) then (是)
  :抛出 ORDER_NOT_CANCEL;
  stop
endif
:regressionStock 回退商品/SKU库存和销量;
:regressionCoupon 回退优惠券状态;
:StoreOrderMapper.deleteById 逻辑删除订单;
if (任一步骤异常?) then (是)
  :事务回滚;
endif
stop
@enduml
```

## 5. 管理端更新/发货订单

- 请求：`PUT /admin-api/order/store-order/update`
- Controller：`StoreOrderController#updateStoreOrder`
- 核心 Service：`StoreOrderServiceImpl#updateStoreOrder`

```plantuml
@startuml
start
:权限校验 order:store-order:update;
:VO 转 StoreOrderDO 并按 id 查原订单;
if (订单不存在?) then (是)
  :抛出 STORE_ORDER_NOT_EXISTS;
  stop
endif
if (操作=发货 且 自取?) then (是)
  :takeStoreOrder -> takeOrder;
  :状态置 3 并奖励积分;
  stop
elseif (操作=发货 且 外卖?) then (是)
  :订单 status=1（待收货）;
elseif (操作=发货 且 堂食?) then (是)
  :保留商业版打印 TODO;
endif
:StoreOrderMapper.updateById;
if (操作=发货?) then (是)
  :写 delivery_goods 状态记录;
  :读取会员;
  note right
    推送消息代码当前被注释，
    不计为实际执行步骤
  end note
  :加入 Redisson 自动收货延迟队列;
endif
:返回成功;
stop
@enduml
```

## 6. 管理端确认退款

- 请求：`POST /admin-api/order/store-order/refund`
- Controller：`StoreOrderController#refund`
- 核心 Service：`StoreOrderServiceImpl#orderRefund`（`@Transactional`）
- 第三方：`PayServiceManager#refundQuery`、`refund`

```plantuml
@startuml
start
:按 id 查询订单并读取会员;
if (订单/会员不存在?) then (是)
  :抛出业务异常;
  stop
endif
if (已退款 或 退款额大于实付额?) then (是)
  :抛出业务异常;
  stop
endif
:设置 refundStatus=2 与 refundPrice;
:生成退款单号;
if (余额支付?) then (是)
  :增加 yshop_user.now_money;
elseif (微信支付?) then (是)
  if (演示模式?) then (是)
    :因无证书抛异常;
    stop
  endif
  if (已有 outTradeNo?) then (是)
    :manager.refundQuery;
    if (退款已成功?) then (是)
      :更新订单并返回;
      stop
    endif
  endif
  :manager.refund;
  if (返回 FAIL?) then (是)
    :抛异常并回滚;
    stop
  endif
  :保存退款单号到 outTradeNo;
elseif (支付宝?) then (是)
  :抛出“暂时不支持退款”并回滚;
  stop
endif
:更新 yshop_store_order;
:写退款收入流水;
:写 refund_price_success 状态记录;
:regressionStock 回退库存;
stop
@enduml
```
