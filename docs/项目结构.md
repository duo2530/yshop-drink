# yshop-drink 后端项目结构

## 分析范围与结论

本文件只分析仓库中的后端工程 `yshop-drink-boot3/`。仓库另外包含两个前端工程：后台管理端 `yshop-drink-vue3/` 与移动/小程序端 `yshop-drink-uniapp-vue3/`；它们仅在结构树中标出边界，不分析其代码。

后端是 Java 17、Spring Boot 3.2.2 的 Maven 多模块工程。根 `pom.xml` 聚合依赖管理、基础框架、启动容器和 10 个业务域模块；业务域通常拆成 `*-api`（跨模块契约）与 `*-biz`（Controller、Service、数据访问和具体实现）。证据：`yshop-drink-boot3/pom.xml`、`yshop-drink-boot3/yshop-server/pom.xml` 及各业务域 `pom.xml`。

## 模块职责

### `yshop-dependencies`

依赖版本管理模块（BOM），供后端所有模块统一引用内部组件和第三方库版本，避免业务模块各自维护版本。它由根工程通过 `dependencyManagement` 导入。证据：`yshop-drink-boot3/pom.xml`、`yshop-drink-boot3/yshop-dependencies/pom.xml`。

### `yshop-framework`

后端通用能力集合，不承载饮品商城的具体业务。其子模块覆盖 Web、安全、MyBatis、Redis、MQ、定时任务、WebSocket、Excel、监控、限流/防护，以及数据权限、租户、IP 等横切能力。证据：`yshop-drink-boot3/yshop-framework/pom.xml` 及该目录下各 `yshop-spring-boot-starter-*` 子模块。

业务模块内部反复出现以下分层：

- `controller/admin`：后台管理接口。
- `controller/app`：用户端/小程序接口。
- `service`：业务编排、校验与事务逻辑。
- `dal/dataobject`：数据库实体（DO）。
- `dal/mysql`：MyBatis Mapper。
- `dal/redis`：模块级缓存访问（仅部分模块存在）。
- `convert`：DTO、VO、DO 之间的对象转换。
- `api` 子模块：供其他业务模块调用的接口、DTO、枚举等跨模块契约。
- `biz` 子模块：接口实现及 Controller、Service、DAL 等可运行代码。

### `yshop-server`

唯一的后端可执行装配模块。`YshopServerApplication` 使用 `@SpringBootApplication` 扫描 `server` 与 `module` 包；`yshop-server/pom.xml` 引入各 `*-biz` 模块并通过 Spring Boot Maven Plugin 打成可执行 JAR。运行环境、数据源、日志及模块开关等配置位于 `src/main/resources/application*.yaml` 和 `logback-spring.xml`。证据：`yshop-drink-boot3/yshop-server/src/main/java/co/yixiang/yshop/server/YshopServerApplication.java`、`yshop-drink-boot3/yshop-server/pom.xml`。

### `yshop-module-system`

系统管理和后台通用业务：管理员登录与验证码、用户/部门/岗位、角色/菜单/权限、字典、租户、通知公告、操作与登录日志、短信、邮件、OAuth2、社会化登录等。模块也含定时任务及 MQ 生产/消费代码。证据：`yshop-module-system-biz/src/main/java/co/yixiang/yshop/module/system/controller/`、`service/`、`dal/dataobject/`、`job/`、`mq/`。

### `yshop-module-infra`

技术基础设施和研发运维能力：文件与文件配置、系统配置、数据源配置、API 访问/错误日志、定时任务及任务日志、Redis 监控、代码生成、WebSocket，并保留一组代码生成演示模型。代码生成模板同时覆盖 Java、SQL 和多套 Vue 结构。证据：`yshop-module-infra-biz/src/main/java/co/yixiang/yshop/module/infra/controller/admin/`、`service/`、`job/`、`websocket/` 以及 `src/main/resources/codegen/`。

### `yshop-module-mall`

商城核心聚合模块，进一步拆成四组 API/Biz 子模块：

- `product`：商品分类、商品主体、SKU/规格属性与属性结果、商品规则、评价，以及 Mapper 中体现的运费模板。证据：`yshop-module-product-biz/.../product/controller/`、`service/`、`dal/dataobject/`、`src/main/resources/mapper/`。
- `shop`：广告、素材及素材分组、面向用户展示的服务项目。证据：`yshop-module-shop-biz/.../shop/controller/`、`dal/dataobject/`。
- `order`：用户下单及后台订单管理、订单购物车快照、订单状态记录、订单号生成、异步订单服务和 MQ 消费。证据：`yshop-module-order-biz/.../order/controller/`、`service/`、`handle/`、`mq/consumer/`、`dal/dataobject/`。
- `store`：门店资料维护和用户端门店查询，带 MySQL 与 Redis 数据访问。证据：`yshop-module-store-biz/.../store/controller/`、`service/`、`dal/`。

### `yshop-module-member`

会员域，负责用户端登录/认证、会员资料、第三方社交账号、微信端入口、收货地址和用户账单；同时提供后台会员、地址、账单管理接口。证据：`yshop-module-member-biz/.../member/controller/app/`、`controller/admin/`、`service/auth/`、`service/user*`、`dal/dataobject/`。

### `yshop-module-marketing`

当前只聚合优惠券子域，负责优惠券配置、用户领取/持有记录以及后台和用户端接口。证据：`yshop-module-coupon-biz/.../coupon/controller/`、`service/coupon/`、`service/couponuser/`、`dal/dataobject/`。

### `yshop-module-score`

积分商城域，包含积分商品、积分订单，以及后台管理和用户端兑换/查询接口。证据：`yshop-module-score-biz/.../score/controller/admin/`、`controller/app/`、`service/scoreproduct/`、`service/scoreorder/`。

### `yshop-module-pay`

支付相关模块。从当前源码可确认的具体业务主要是商户支付配置/明细的 Controller、Service、DO、Mapper，并包含 `http` 包用于支付侧 HTTP 交互；不应仅凭模块名推断其已实现所有支付渠道或完整支付回调体系。证据：`yshop-module-pay-biz/.../pay/controller/admin/merchantdetails/`、`service/merchantdetails/`、`dal/dataobject/merchantdetails/`、`http/`。

### `yshop-module-express`

快递/物流模块，提供后台与用户端物流接口、快递配置/记录的服务和 MySQL/Redis 访问。证据：`yshop-module-express-biz/.../express/controller/admin/`、`controller/app/`、`service/express/`、`dal/`。

### `yshop-module-message`

消息模块，当前主要围绕微信模板消息配置与发送，并具有 MQ consumer/producer、Redis 消息模型和供应实现。证据：`yshop-module-message-biz/.../message/controller/admin/`、`service/wechattemplate/`、`mq/`、`redismq/`、`supply/`。

### `yshop-module-mp`

微信公众号管理模块，覆盖公众号账号、菜单、素材、草稿、发布、标签、粉丝、消息、自动回复、统计和开放回调等。证据：`yshop-module-mp-biz/.../mp/controller/admin/`、`service/`、`framework/mp/`、`dal/dataobject/`。

## 装配关系与边界

1. 根 `pom.xml` 负责聚合构建，`yshop-dependencies` 管版本，`yshop-framework` 提供横切能力，`yshop-server` 负责把业务实现装入一个 Spring Boot 进程。
2. 业务域以 API/Biz 拆分，跨模块依赖应面向 `*-api` 契约；具体 Web、Service 和数据库实现位于 `*-biz`。
3. `admin` 与 `app` Controller 共处同一个后端部署，但分别服务后台管理前端和用户端/小程序。
4. `yshop-drink-vue3` 和 `yshop-drink-uniapp-vue3` 是后端 API 的消费者，不属于后端 Maven reactor，也未参与本文件的代码职责推断。

## 结构统计

- 后端根 `pom.xml` 直接聚合 13 个一级 Maven 模块：1 个依赖 BOM、1 个框架聚合、1 个启动模块、10 个业务域聚合模块。
- `yshop-framework` 下有 15 个基础模块（含 `yshop-common`）。
- 10 个业务域聚合模块中，商城域包含 8 个 API/Biz 子模块；其余 9 个业务域各包含 2 个 API/Biz 子模块，共 26 个业务子模块。
- 仓库内另有 2 个前端工程，已明确排除在后端代码分析范围之外。
